# 하방 변동성 사이징 — 프로젝트 컨텍스트

암호화폐 포지션 사이징 전략. **연구는 끝났고 결론이 났다.**
이 문서는 이미 검증하거나 기각한 것을 다시 시도하지 않게 하려고 쓴다.

## 확정된 것

```python
neg  = r.clip(upper=0)
dvol = np.sqrt((neg**2).rolling(30).mean()).shift(1)   # shift(1) 필수
position = clip(scale/dvol, 0, 1.0)                     # scale 은 walk-forward 추정
```

| 파라미터 | 값 | 근거 |
|---|---|---|
| `WINDOW` | 30 | 25~40 고원 확인. **유일하게 민감한 파라미터** |
| `MAXLEV` | 1.0 | 1.5·2.0 은 MDD 악화 (-45.8% → -64.2%) |
| `EXPOSURE` | 0.85 | 위험선호도. 미검증이나 대조군도 같이 움직여 영향 작음 |
| `BURN` | 252 | 민감도 없음 (126~504 동일) |
| `REBAL` | 30 | 민감도 없음 (1~120일 동일) |
| `FEE` | 0.0005 | 편도 0.05% |

**성과 (walk-forward, 고정레버 대조군 대비 Sharpe)**
BTC 전체 +0.040 / ETH +0.097 / BTC 후반 +0.040

## 가장 중요한 단서 — 우위는 국면에 몰려 있다

| 국면 | B&H | 대조군 | 확정판 | 판정 |
|---|---:|---:|---:|:--|
| BTC 2022 폭락 | -72.8% | -67.4% | -71.2% | **패** |
| BTC 2023-24 상승 | 563.6% | 532.3% | 562.7% | 승 |
| BTC 2025-26 하락 | -40.0% | -37.1% | -37.5% | **패** |
| ETH 2022 폭락 | -72.4% | -66.0% | -68.9% | **패** |
| ETH 2023-24 상승 | 226.3% | 218.4% | 242.9% | 승 |
| ETH 2025-26 하락 | -50.7% | -45.8% | -47.6% | **패** |

**하락 국면 4곳 전부 대조군에 진다.** 전체 우위는 상승장 한 구간에서 나왔다.

이유: 하방변동성은 *이미 떨어진 뒤* 포지션을 줄이고, 폭락 후 변동성이 높게 유지되는
동안의 급반등을 놓친다. 하락장은 상시 고변동이라 사실상 고정레버와 같아진다.

> **낙폭 방어 전략이 아니라 '상승장 안에서 조정을 피하는' 전략이다.**
> 2026-09 현재는 고점 대비 -40% 국면이라, 지금 투입하면 고정레버 0.85와 실질적으로 같다.

## 이미 기각됨 — 다시 시도하지 말 것

| 시도 | 결과 |
|---|---|
| LSTM 가격 예측 (원본 삼성전자 방식) | naive(전일가)에 패배 |
| LSTM 방향 예측 + 기술지표 23개 | 50~52%, 이항검정 **p=0.41** |
| 방향 예측 백테스트 7종 | 전부 Buy & Hold 에 패배 (최고 +33% vs B&H +112%) |
| LSTM 변동성 예측 | EWMA **한 줄**에 패배 (corr 0.067 vs 0.309) |
| LSTM 모델 키우기 (hidden 64, 2층) | 32/1층보다 **나쁨** (49.5% vs 51.8%) |
| 전체(하방 아닌) 변동성 사이징 | 대조군 못 이김. 창 10~90 **전부** 실패 |
| 하방+추세 결합 | BTC 우수하나 ETH 열세, 파라미터 3개 |
| 하방 창 15/20/50/60/90일 | 세 검증 동시 양수 실패 |

**핵심 교훈: 네 번 시도해서 네 번 다 단순한 방법이 LSTM을 이겼다.**
일간 OHLCV에는 방향 정보가 없다. 모델 용량은 공짜가 아니다.

## 방법론 규칙 — 이 프로젝트에서 새 아이디어를 검증할 때 반드시 지킬 것

이 규칙들은 실제로 여러 번 잘못된 결론을 잡아낸 것들이다.

1. **대조군 없는 숫자는 무의미하다.** 방향 예측은 naive(전일가), 사이징은
   고정레버(같은 평균 노출도)와 비교하라. 전체 변동성 사이징이 여기서 걸렸다.

2. **평균 노출도를 통일하라.** 상승장에서는 노출 높은 쪽이 실력과 무관하게 이긴다.
   `calibrate()` 로 평균 레버리지를 맞춘 뒤 비교해야 타이밍 능력만 남는다.

3. **파라미터는 고원(plateau)을 확인하라.** 한 값만 좋으면 그 값을 고른 것이다.
   인접값이 연속으로 좋아야 신호다. 하방 25/30/35/40 이 그랬다.

4. **비교는 동일 표본에서.** 창 길이나 burn-in 을 바꾸면 시작일이 달라진다.
   고정 burn-in 을 줘서 맞추지 않으면 결론이 뒤집힌다 (실제로 뒤집혔다).

5. **학습이 들어가면 seed 를 10개 돌려 분산부터 재라.** LSTM 은 seed 만 바꿔도
   Sharpe 가 48.5%~53.6% (폭 5%p) 로 흔들렸다. 그보다 작은 '개선'은 노이즈다.
   결정론적 방법(EWMA 등)은 소수점까지 재현되므로 이 문제가 없다.

6. **거래비용을 처음부터 넣어라.** 방향 전략은 비용 전 +41% 가 비용 후 -22% 였다.

7. **외부 검증 필수.** BTC 에서 통한 건 ETH 와 다른 기간에서도 확인하라.

8. **전체 숫자를 봤으면 국면별로 쪼개라.** 전체가 좋아도 한 국면에 몰려 있을 수 있다.
   이 프로젝트의 마지막 발견이 정확히 그것이었다.

9. **`.shift(1)` 을 절대 빼지 말 것.** 빼면 미래를 보고 매매하는 것이라
   결과가 환상적으로 좋아진다.
